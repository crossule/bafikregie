# BAFIK Medical Congress

Site officiel de BAFIK — production, diffusion et valorisation de congrès scientifiques en Afrique.

## Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- next-intl (FR par défaut, EN en option)
- Framer Motion

## Démarrage

```bash
npm install
cp .env.example .env.local   # puis remplir les valeurs
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000)
